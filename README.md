# Messenger App 💬

A beginner-friendly messaging web application that I am developing as a hands-on learning project.

## 📌 About the Project

The goal of this project is to build a simple messaging application while learning web development, JavaScript and Python Flask.

I am developing this project step by step, starting with the user interface and gradually adding backend functionality.

## 🛠️ Technologies Used

- HTML – Webpage structure
- CSS – Styling and layout
- JavaScript – Frontend interactions
- Python – Backend programming
- Flask – Python web framework

## ✨ Current Features

- Dark-themed Messenger interface
- Sidebar with sample contacts
- Chat conversation area
- Message input field
- Send button
- JavaScript-based message display
- Enter key support for sending messages

## 🚀 Run Locally

1. Install Python.
2. Install Flask:

   `pip install flask`

3. Start the application:

   `python App.py`

4. Open your browser:

   `http://127.0.0.1:5000/`
